### Selected work

- **[Calm Harm](https://apps.apple.com/gb/app/calm-harm/id961611581)** — a React
  Native app helping young people manage the urge to self-harm. More than two
  million downloads, and a DBA Design Effectiveness Gold.
- **[DigiBete](https://www.digibete.org/)** — a Laravel and Filament platform
  for families managing type 1 diabetes. DBA Silver and UK Dev Awards App of the
  Year.
- **[Sitwell CC](https://www.sitwell.cc)** — the Rotherham cycling club’s site
  in Astro, React and Tailwind, edited through Sanity.
- **[Skillswap](https://skillswap.colouringcode.com)** — a community
  skill-swapping platform in TypeScript, React and PostgreSQL.
